# 平均教师（PPT 机器）vs 优秀教师 — 差距分析与产品化

> 这是整个项目最核心的设计哲学文档。
> 起点是一个真实时刻（2026-07-05）：第一批 3D demo 做出来，视觉很好，
> 用户的评价却是 **"looks great, however, not pedagogically make sense"**。
> 从那天起，项目的真正命题变成：**AI 很容易堆出「好看的学习内容」，
> 怎么让它产出「有教学目的的学习体验」？** 答案是先回答：优秀教师到底比 PPT 机器多做了什么。

---

## 一、差距解剖

| 维度 | 平均教师（PPT 机器） | 优秀教师 | 产品化落点 |
|------|---------------------|----------|-----------|
| **备课起点** | 打开教材，按页序做成幻灯片 | 先问「这门课学生必须**得到**的 2–5 个洞见是什么？」 | STEP-0 Aha Keys：规划 LLM 必须先蒸馏顿悟点，再排一切 |
| **知识组织** | 线性罗列知识点 | 心里有一张图：什么是先修、什么围绕什么、哪里学生会断链 | Knowledge Graph 硬锚点：nodes+edges，大纲必须按边的顺序走图 |
| **对误解的态度** | 不知道/不处理学生的错误直觉 | **预判**误解，设计体验专门打掉它 | 每个 aha 带 `misconception` 字段；阅读先点破、交互演示打脸、测验干扰项就是误解本身 |
| **讲抽象概念** | 把结论写在幻灯片上让学生读 | 让学生**操作**出结论（先预测→动手→观察→说出来） | `buildIdea` + Construct 规则：交互节主角必须可操作，「禁止把结论直接写在屏幕上」 |
| **例子** | 每页换一个不相关的例子 | 一个主例贯穿全课，不断加深 | `anchorExample` 字段：全课共用一个 running example |
| **用图** | 图是装饰 | 图是最密的知识载体（几何总表、机制图） | 图打标（relevance/visualSummary）+ 规划必须从核心图抽节点 |
| **考试** | 复述例题、换数字 | 换故事外壳考同一结构——检验的是钥匙不是记忆 | Transfer 规则：每个 aha ≥1 道全新情境题；「只背例题的学生做不对」是出题验收标准 |
| **模态选择** | 有什么工具用什么（全 PPT / 全视频） | 按认知需要选：空间概念上模型，参数关系上交互，叙述上文本 | 空间性检验：VR 只给内在 3D 结构的概念；2D 交互给 H5；其余 reading |
| **课程完整性** | 讲完拉倒 | 铺垫→建构→检验闭环，缺一环补一环 | 管线强制 ≥1 reading + ≥1 quiz；每个 aha 必须有安装节（installsAha 校验 + 兜底） |
| **面对新材料** | 复用旧课件 | 从**这份**材料出发重新设计 | Source Lock：绑定 jobId/filename，禁止复用上一份材料的 aha/节点 |

## 二、一句话版本

> **PPT 机器传输信息；优秀教师安装钥匙。**
> 信息可以罗列，钥匙必须由学生亲手建构——所以优秀教学天然是
> 「点破误解（scaffold）→ 动手建构（construct）→ 换皮验证（transfer）」的三段闭环。

## 三、为什么 LLM 默认是 PPT 机器

1. **训练分布**：互联网上的「教学内容」绝大多数就是知识点罗列，模型模仿众数。
2. **省力路径**：把教材段落改写成漂亮卡片，比设计一个能打脸误解的交互便宜得多——不给硬约束，模型永远走省力路径。
3. **无验收标准**：「生成一门课」没有 fail 条件；「每个 aha 必须有交互安装节、测验必须换皮」有 fail 条件。
4. **好看 ≠ 有效的评估陷阱**：人类快速浏览时也会把「精美」误判为「优质」——demo 阶段的我们就是这样被骗的。

**所以解法不是更好的措辞，而是把上表右列变成 schema + 校验 + 生成规则**（详见 [aha-keys-and-knowledge-graph.md](./aha-keys-and-knowledge-graph.md)）。教育学必须编译成数据契约才能约束 LLM。

## 四、检验清单：你的学习产品是 PPT 机器吗？

对任何一门 AI 生成的课程，问：

- [ ] 删掉所有配图和 3D，这门课的**教学策略**还剩什么？（剩知识点列表 = PPT 机器）
- [ ] 能指出每个交互体验**打掉哪个具体误解**吗？
- [ ] 把测验题的故事外壳换掉，答案结构还成立吗？学生还能做对吗？
- [ ] 有没有一个概念是「用到了但从来没教过」？（KG 校验点）
- [ ] 3D/交互内容如果换成一张静态图，学习效果损失多少？（损失小 = 这个 3D 是装饰）
- [ ] 一个只背了例题的学生能不能通过最终测验？（能 = transfer 失败）

## 五、边界与诚实的局限

- 本项目**没有**学生侧掌握度追踪（aha 是否真的装进脑子无 runtime 度量）——目前靠内容设计保证概率，不靠测量闭环。这是下一个产品该补的环。
- 「优秀教师」还有本产品完全没碰的维度：临场应变、情感联结、对具体学生的记忆。文档所述只覆盖**教学设计**这一层。
- 三段闭环对**技能型**内容（背单词、肌肉记忆类）不是最优解——那类内容间隔重复比顿悟建构更重要，别硬套。
