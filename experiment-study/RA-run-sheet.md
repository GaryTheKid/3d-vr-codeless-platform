## Steps

1. **Start Zoom + record.** Create the meeting, turn **cloud recording** on before they join (or as soon as they join).

2. **Greet (1 min).** Brief: this is an AI tool that turns teaching PDFs into a multimodal course (reading / quiz / H5 / 3D). No right/wrong about opinions; ~60–90 min; Zoom is recorded for notes.

3. **Randomly pick one pack** from the table. Note pack #. Don’t let them choose.

4. **Pre-test.** Send that pack’s quiz HTML link. Ask them to open it, put **P0x** in the name field, answer without looking things up.

5. **Collect pre answers.** On finish → **Download Answer Sheet (.txt)** → send the file to you. Save as `P0x_pre_answers.txt`.

6. **Open the system + matching sample.** Send the system URL. Chrome/Edge on a computer; screen share. Folder icon (Projects) → open the **sample** for the pack you picked (see table). Then **Start Learning**.

7. **Watch the full course.** Note **learn start** and **learn end**. Ask if they opened every section at least once. Help with buttons only — don’t teach the topic.

8. **Post-test.** Same quiz HTML as pre-test (fresh tab so old answers aren’t still filled). Code **P0x** in the name field.

9. **Collect post answers.** Download `.txt` → send to you. Save as `P0x_post_answers.txt`.

10. **Questionnaire.** Send [questionnaire.html](https://github.com/GaryTheKid/Demo/blob/main/experiment-study/questionnaire.html). Fill → download answers → send to you. Save as `P0x_questionnaire.txt`.

11. **Interview (5–10 min).** Use the outline below.

12. **Close.** Optional short casual chat for more feedback. Thank them. **Stop / save the Zoom recording** before you leave.

13. **After session.** On the Zoom web portal: confirm the recording is saved → **transcribe** → send the transcript to the study lead. Also send pre/post/questionnaire files + your notes (`P0x_notes`).

## Interview (semi-structured)

Follow up short answers with *“Can you give an example?”*

1. In one sentence, what does this tool do?
2. How did waiting / loading feel?
3. Which part helped most — reading, quizzes, interactive, or 3D? Why?
4. Where were you confused or annoyed?
5. Did the course match the topic — too shallow, about right, too much?
6. Would you use it for studying? For teaching someone else?
7. If we fix only one thing, what?
8. Anything else?
