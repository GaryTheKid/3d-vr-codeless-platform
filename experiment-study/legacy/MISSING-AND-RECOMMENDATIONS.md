# Before you start (course-project checklist)

Keep this short. You don’t need IRB theater for a class project — just be polite and clear with classmates/volunteers.

## Must do

1. Paste **`{{SYSTEM_URL}}`** into the RA protocol.  
2. One **dry run** with a friend (generation wait can be long).  
3. Decide how people answer: Google Form, shared doc, or paste into chat.  
4. Tell people: Chrome/Edge desktop, ~90–120 min, you’ll record if they’re OK with it.  
5. Assign PDFs with the simple shuffle in `RANDOMIZATION.md` (don’t let them cherry-pick).

## Nice if you have time

- Ask them to screen-share while learning (so you know they finished).  
- Note crashes / “RA helped click” in the timing CSV notes column.  
- Ask: “Did you open every outline section once?” before post-test.

## Don’t bother (for this course project)

- Formal IRB protocol numbers  
- Cronbach’s α / heavy stats  
- SUS + Paas + eye-tracking  
- Perfect counterbalancing / power analysis  
- Publishing-grade consent vaults  

If something breaks mid-session: write a note, collect what you can, move on.
