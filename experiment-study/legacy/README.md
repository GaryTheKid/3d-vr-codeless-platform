# XR EduAgent — Course-project usability study pack

**Level:** course project (lightweight) · **not** a PhD / journal-grade study  
**N ≈ 8–10** · Zoom remote · subjective UX + simple learning check + short interview

This folder is just so your team can **run sessions and write the class report** without over-engineering.

## Folder map

| Path | What |
|------|------|
| `protocol/RA-PROTOCOL.md` | What to say / do on the call |
| `protocol/SESSION-TIMELINE.md` | Rough timing |
| `protocol/RANDOMIZATION.md` | Assign 1 of 5 PDFs |
| `consent/INFORMED-CONSENT.md` | Short disclaimer + chat consent |
| `instruments/` | Demographics, TLX, Likert, interview |
| `instruments/prepost/` | Pre/post quizzes + answer key |
| `timing/TIMING-LOG.csv` | Gen time + learn time |
| `data/ANALYSIS-PLAN.md` | Easy quan + qual for the report |
| `data/DATA-DICTIONARY.md` | Spreadsheet column names (optional) |
| `materials/` | 5 PDFs |
| `MISSING-AND-RECOMMENDATIONS.md` | Only the must-haves before you start |

## Flow

Consent → short pre-quiz → open system → upload PDF → Build → wait for ✓ → Start Learning → finish → post-quiz + TLX + satisfaction → short interview → done.

## Before first participant

1. Put your live URL into `protocol/RA-PROTOCOL.md` (`{{SYSTEM_URL}}`).
2. Try **one dry run** with a classmate (timing check).
3. Use Google Form / chat / shared doc for answers — whatever is fastest. Markdown here is the master text only.
