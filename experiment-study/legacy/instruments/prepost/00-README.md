# Pre/Post tests — instructions

- Use the **same** item set for pre and post (learning gain = post − pre).  
- Give **pre before PDF**; **post after learning pass**.  
- Shuffle option order only if you keep a mapping; simplest: **identical forms**.  
- Score with [`ANSWER-KEYS.md`](./ANSWER-KEYS.md).

Each quiz: **6 items** (4 MCQ + 2 short). Max score **8** (MCQ=1 each; short=0/1/2 by key).
