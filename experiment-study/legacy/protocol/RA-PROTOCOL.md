# RA Protocol — XR EduAgent (course project)

**Audience:** teammates running Zoom sessions  
Keep it friendly and practical. No need to sound like a formal lab.

**Replace** `{{SYSTEM_URL}}` with your live site URL.

---

## Roles (3 people)

| Role | Jobs |
|------|------|
| **Host** | Talk to participant, move stages along |
| **Timer** | Fill `timing/TIMING-LOG.csv`, watch the clock |
| **Tech** | Zoom / links / “where’s the button?” rescue |

---

## Before the call

1. Give them an ID: `P01`…  
2. Assign a PDF (`RANDOMIZATION.md`) → note MaterialID.  
3. Open system URL, that PDF, matching pre-test.  
4. Start Zoom; ask if recording is OK.

---

## Script

### A. Hi (2–3 min)

Thanks for joining — course project testing an AI teaching tool. No wrong opinions. ~90–120 min.

### B. Consent (2 min)

Paste `consent/INFORMED-CONSENT.md`. Wait for `OK — I agree…` in chat.

### C. Demographics (2–3 min)

Send `instruments/01-demographics.md` (or a quick Form). Skip unused fields if rushed.

### D. Pre-test (8–12 min)

Same MaterialID quiz in `instruments/prepost/`. **No PDF yet.** Guessing is fine.

### E. Tiny intro (3–5 min)

> Upload the PDF → Build from this → wait until every outline section has a check → Start Learning → go through the course.

Optional 30-sec point-at-buttons. Don’t build a full demo course for them.

### F. Generate (often 15–45 min)

Send URL + their PDF. Timer starts when Build starts (`gen_start` → `gen_end` when all ✓).  
Help only with UI (“that button”), not subject content.  
If stuck forever: note it, skip to ratings about the wait, still do a short interview.

### G. Learn (20–40 min)

Start Learning → `learn_start` / `learn_end`.  
Ask at the end: “Did you open every section once?”

### H. Scales (10–15 min) — keep this order

1. Post-test (same as pre)  
2. NASA-TLX  
3. Satisfaction Likert  

### I. Interview (10–15 min)

`instruments/07-interview-guide.md` — you don’t need every question.

### J. Thanks (1–2 min)

Stop recording. Save notes as `Pxx_…`. Done.

## Quick fixes

| Issue | Do |
|-------|----|
| Won’t load | Chrome/Edge; resend link |
| Upload fail | Resend PDF |
| Build stuck | Wait a bit; refresh once; else log & continue with what you have |
| Start Learning grey | Not all ✓ yet |
| 3D black | Switch section and back / refresh |
