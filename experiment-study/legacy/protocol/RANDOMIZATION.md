## Rule (simple, for N≈8–10)

Use a **balanced draw** so each PDF is used ~2 times:

1. Before the study, shuffle this list of 10 slots (2× each material):  
   `M01,M01,M02,M02,M03,M03,M04,M04,M05,M05`
2. Assign slot 1 → P01, slot 2 → P02, …
3. If a participant drops, reuse their slot for the replacement participant.
4. **Do not** let participants choose freely (selection bias). “Randomly select” in the study means **RA-assigned random**, then tell them “today’s packet is this PDF.”
