# Session timeline (target)

Total: **~90–120 minutes**. Generation time dominates variance — don’t cut post-test or TLX.

| Stage | Clock | Soft max |
|-------|-------|----------|
| A Welcome | 3 min | 5 |
| B Consent | 5 min | 8 |
| C Demographics | 3 min | 5 |
| D Pre-test | 10 min | 15 |
| E System intro | 5 min | 7 |
| F Course generation | 15–40 min | 50 (then escalate) |
| G Learning pass | 20–40 min | 45 |
| H Scales (post → TLX → satisfaction) | 15 min | 20 |
| I Interview | 15 min | 20 |
| J Debrief | 3 min | 5 |

## Buffer rules

- If generation finishes in <10 min, use spare time for a calmer learning pass (no extra tasks).
- If generation >40 min and still incomplete: PI call — usually **stop learning**, still collect TLX/satisfaction about the *authoring wait*, mark learning as N/A, keep interview focused on generation UX.
- Never reverse instrument order.
